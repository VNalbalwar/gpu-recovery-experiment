Tesla T4 figure set

Important scope note:
The T4 dataset does not contain the same 5-duration sweep used for the RTX 4060.
Therefore Figures 1 and 2 are explicitly labeled as 100 ms L2 measurements,
not duration-sweep figures.

Figure 3 uses the three 100 ms calibration trials.
Figure 4 uses the 20-trial extended dataset (10 control + 10 interference).
Figure 5 is a descriptive temporal analysis of interference-condition recovery probes.

All normalized latency values use each trial/run's own baseline median.
No significance annotations are included.
